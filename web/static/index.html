    How estimates work

    Expected cost includes prompts, context and output. Revision uses verified matching calibration when available, or the heuristic all-cues-edited proxy otherwise. Sensitivity ranges are not guaranteed bounds. The conservative scenario and authorized limit stay unchanged.

    The extreme conservative scenario assumes maximum context and glossary growth, token consumption and all permitted retries. It is not the authorized budget.

    The application-level guard checks actual spending, unresolved reservations and the next request allowance before each request. Translation or revision may pause before completion if the remaining budget is insufficient. This guard is not an absolute provider billing cap.
